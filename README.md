手机试玩：[打开虚拟人生](https://zhangjie2759.github.io/GAME-004-playtest/)

公开仓库：[GAME-004-playtest](https://github.com/zhangjie2759/GAME-004-playtest)

董事长处理七日新品发布危机，牛马在虚构互联网公司收集工作记录、客户确认与同事证言，完成职场翻盘。每条路线有12位成年虚构联系人、27个事项和4类结局。人物会记得前几天的承诺、朋友圈互动和金钱边界，并在后续私聊与最终回信中回应。

## 开始试玩

1. 选择职业路线，再选人设、填写昵称。没有账号或密码。
2. 读未读消息，选择快捷回复。聊天底部可直达下一个待处理事项。
3. 任意聊天点“＋”可主动发红包或转账；NPC也会在适合的剧情发来红包。点击卡片可领取或退还，不同处理会改变后续关系。
4. 在“发现 → 朋友圈”点赞、评论、发布动态。每天可发布一条。
5. 第一天处理三件事，之后每天还有一段跨日关系回响。全部事项和收到的红包处理完后，找董事长办助理 / 行政小唐“结束今日”。
6. “我 → 服务 → 钱包”查看余额、8张虚构银行卡、账单、收付款测试页。
7. “我 → 设置”可重开选择路线，或永久清除本地存档。

旧存档会继续原董事长故事并保留余额；要体验牛马路线，请在设置中重新开始，这会清除当前这一局。

## 本地运行与测试

需要 Node.js 20 或更新版本，无需安装依赖。

~~~powershell
node server.mjs
~~~

打开 http://127.0.0.1:4174/ 。不要双击 index.html；ES Modules 需要 HTTP 服务。服务器仅监听本机，通过白名单提供前端资源，不暴露项目档案。

~~~powershell
node --test rules.test.mjs
~~~

规则测试覆盖双路线150种回复、八类结局、跨日关系回响、双向红包、金额与余额、幂等、存档迁移与坏档恢复。浏览器验收包含360×800、390×844、430×932视口的两条七日流程。

结局复现：董事长全选第一项 → 稳健发布；最后选第二项 → 延期保口碑；前面第二项、最后第三项 → 爆款团队失和；全选第三项 → 失控。牛马全选第一项 → 翻盘；最后第二项 → 体面离开；最后第三项 → 赢事实失信任；全选第三项 → 背锅。社交互动可能改变临界结果。

## 边界与扩展

当前为预设对白＋程序规则，真实模型尚未接入。异步 Provider 会提供经过筛选的人物记忆和待处理红包；允许意图校验、超时降级与后端客户端示例见 API_INTEGRATION.md。可从 SCENARIOS 扩展路线与角色。

所有公司、角色与交易均虚构；无真人照片、真实支付、账号、追踪器、模型密钥或后台世界。界面采用原创“微讯”品牌与熟悉的聊天交互，并非微信官方产品。12张头像为项目原有原创生成图片，角色分路线映射使用。

进度只保存在当前浏览器，清除后不可恢复。关闭页面期间故事不会推进。预计每条路线20–30分钟，阅读节奏与真实感仍待 Jay 手机试玩验收；项目保持 PROTOTYPING。
