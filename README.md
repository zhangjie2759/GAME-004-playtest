# 董事长日常 · H5 v0.1

七个虚拟工作日，12 位成年虚构联系人，21 个决策事项。通过聊天、朋友圈、点赞、评论、虚拟红包和转账，处理澄屿科技新品“拾光一号”的发布危机。

手机在线试玩：<https://zhangjie2759.github.io/GAME-004-playtest/>

公开仓库：<https://github.com/zhangjie2759/GAME-004-playtest>

## 本地运行

需要 Node.js 20 或更新版本，无需安装依赖。在本目录执行：

```powershell
node server.mjs
```

浏览器打开 http://127.0.0.1:4174 。不要双击 index.html 使用 file://，ES Modules 需要 HTTP 服务。关闭启动该服务的终端会停止访问。服务只监听本机，并仅提供六个前端文件，不暴露项目档案。

## 操作

1. 在登入页选择“超级大帅哥 / 富豪 / 富婆 / 牛马逆袭”人设并填写称呼。四种人设改变初始公司处境；首版都从已经成为董事长的节点进入同一场七日危机。
2. 点有未读消息的联系人，选择下方快捷回复；虚拟拨款、红包需确认。
3. 新事项依序进入其他会话。点聊天底部“查看下一条待处理消息”可直达。
4. 在“发现 → 朋友圈”点赞、评论或点相机发布动态。每天可发一条，反馈影响隐藏状态。
5. 每天三件事处理完，找助理“结束今日”。七天后收下回信；可继续查看历史或重玩。
6. “我 → 服务”可进入虚构钱包、8 张虚构银行卡、账单和不可扫描的测试收付款页；初始虚拟余额为 `¥88,888,888.88`。
7. “我 → 设置”可重新开始或永久清除本站本地存档。

## 验证

```powershell
node --test rules.test.mjs
```

四条可复现路线：全部选第一项 → 稳健发布；前面选第一项、最后延期 → 延期保住口碑；前面选第二项、最后全面首发 → 爆款但团队失和；全部选第三项 → 双重失控。动态互动可能改变临界结果。

## 边界

这是预设分支内容 + 程序规则的测试原型，没有真实 AI、真实交易、账号、推送、追踪器或外部网络调用。用户称呼、选择和聊天仅保存在当前浏览器。关闭页面期间故事不会推进。微信式高保真界面用于测试，并非微信官方产品；未复制微信源码、截图或官方标志。12 张头像均为原创生成的虚构素材，不指向真人、公众人物或品牌。钱包、银行卡、红包、转账与账单均为虚构测试，不能支付或提现。

20–30 分钟为预期阅读试玩时长，尚需 Jay 人工计时验证，自动跑通不代表有趣或达到真实感标准。
